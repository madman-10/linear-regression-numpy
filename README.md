# Linear Regression from Scratch

A lightweight NumPy implementation of Linear Regression using gradient descent.

## Prerequisites

```bash
pip install numpy matplotlib scikit-learn

```

## Usage

```bash
python main.py

```

## Overview

* **`LinearRegression` Class**: Trains weights and bias using gradient descent optimization.


* **Evaluation**: Computes Mean Squared Error (MSE) on test data.


* **Visualization**: Plots the training/test data and the regression line using Matplotlib.
